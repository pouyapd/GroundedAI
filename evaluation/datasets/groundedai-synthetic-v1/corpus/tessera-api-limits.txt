Tessera Public API - Rate Limits and Errors

Quotas and rate limits

The free tier allows 10,000 requests per day with a burst limit of 20 requests per second. The pro tier allows 250,000 requests per day with a burst limit of 100 requests per second. Quotas reset at 00:00 UTC.

Handling HTTP 429

When a client exceeds a limit, the API answers with HTTP status 429 Too Many Requests. The response contains a Retry-After header with the number of seconds to wait. Clients should retry with exponential backoff, starting with a delay of 1 second and making at most 5 retries.

Maintenance

Planned maintenance takes place on Sundays between 02:00 and 03:00 UTC. During maintenance the API may answer with HTTP status 503 Service Unavailable.

Requests

The maximum request body size is 2 MB. List endpoints are paginated, and the maximum page size is 200 items. All timestamps use ISO 8601 in UTC.

Authentication

Every request needs an API key in the Authorization header. API keys must be rotated every 90 days; the developer console shows a warning 14 days before a key expires.

Error format

Errors are returned as JSON objects with the fields code, message and request_id. Include the request_id when contacting support.
